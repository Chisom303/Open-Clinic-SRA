# Security Policy

## Our design commitment

Open Clinic SRA runs entirely in the user's browser. Assessment answers are
stored only on the user's device and are never transmitted to any server
operated by this project. Any change that would send answers off-device will
not be accepted.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email **[MAINTAINER EMAIL — replace before publishing]** with:

- a description of the issue and its impact,
- steps to reproduce, and
- any suggested fix.

You'll receive an acknowledgment within 5 business days. We'll credit
reporters in the release notes unless you prefer to remain anonymous.

## Scope

In scope: the web app, the scoring engine, report generation, and any build
or CI configuration in this repository.

Out of scope: the accuracy of regulatory content (please open a normal issue
labeled `accuracy` instead).
