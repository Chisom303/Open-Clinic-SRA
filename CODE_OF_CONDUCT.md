# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers (many of our
contributors are clinic staff, not developers), and keep discussion focused on
making the tool better and more accurate.

Report unacceptable behavior privately to the maintainers at
**Aloziechisom23@gmail.com**. All reports will be reviewed and handled
confidentially.
